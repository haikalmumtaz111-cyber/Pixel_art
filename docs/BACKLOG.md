# Catatan Peningkatan

Daftar keterbatasan yang ditemukan saat meninjau hasil setiap tahap. Semua pengujian otomatis lulus, jadi butir-butir di bawah bukan kesalahan yang memblokir. Daftar ini adalah bahan peningkatan untuk tahap berikutnya. Butir lama tidak dihapus; yang sudah beres diberi status.

Prioritas: **Tinggi** = paling terasa di hasil atau paling berisiko, **Sedang** = layak dikerjakan di tahap berikutnya, **Rendah** = penghalusan.

Kondisi terakhir: Tahap 3 disetujui dan di-merge ke `main` (PR #3). Tahap 4 (kamera pixel-perfect, fokus V14) disetujui pemilik dan di-merge ke `main` (PR #4), termasuk perubahan hasil render Project B. Audit final PR #4 (clean clone) lulus di semua pemeriksaan wajib. Dua temuannya dicatat sebagai V24 dan V25. Setelah Tahap 4, baseline regresi dibuat berversi dan Project B memakai baseline resmi Tahap 4 (PR #5, disetujui dan di-merge ke `main`); audit final PR #5 mencatat T17 dan T18. T17 selesai lewat PR #6 (di-merge ke `main`). Pemilik mengaktifkan ruleset GitHub untuk `main` dan branch Tahap 1-4 (28 Oktober 2026), sehingga T18 sebagian selesai. Tahap 5 (gerak dan pencahayaan karakter, fokus V15 dan V16) disetujui pemilik dan di-merge ke `main` (PR #9). Fiturnya opsional per karakter, jadi ketiga film lama tidak berubah; temuannya dicatat sebagai V26-V28 dan T19. Setelah itu pemilik menambahkan pola `tahap-5-*` ke ruleset branch historis (T18), dan kebocoran folder sementara di unit test baseline (temuan audit setelah Tahap 5) diperbaiki lewat PR #10. Baseline resmi demo `character-lab` (`tahap-5`, dari `main@e6926d2`) direkam atas perintah pemilik lewat PR C dan di-merge ke `main` (PR #12, `09d68e9`). Audit pasca-merge PR #12 (clean clone) tidak menemukan masalah di kode, render, baseline, maupun CI. PR D (T19, pemeriksaan pose karakter) dikerjakan atas persetujuan pemilik dan di-merge ke `main` (PR #14, `0f2b33d`); pemeriksaan barunya menemukan V29-V32, yang dilaporkan validator sebagai KNOWN ISSUE (V31 dan V32 disetujui pemilik sebagai KNOWN ISSUE sementara pada 29 Oktober 2026, belum diperbaiki). Audit pasca-merge PR #14 (clean clone) tidak menemukan masalah di kode, render, baseline, maupun CI. Dua temuannya ada di dokumentasi (status merge PR D dan cakupan BACKLOG di CLAUDE.md) dan diperbaiki lewat koreksi dokumentasi susulan (PR #15, `9971143`); audit pasca-merge PR #15 tidak menemukan FAIL. Sebelum Tahap 6 dimulai, pemilik menambahkan pola `tahap-6-*` ke ruleset branch historis (29 Oktober 2026, T18); saat itu Tahap 6 belum dimulai. Peringatan deprecation Node.js 20 di log GitHub Actions dicatat sebagai T20. Dokumentasi T18 dan pola `tahap-6-*` disinkronkan lewat PR #16 (`97fbc2e`), lalu T20 selesai lewat PR #17 (`b03f344`): action CI naik ke v5 (runtime Node.js 24) dan peringatan "Node.js 20 is deprecated" hilang, tetapi `setup-node@v5` masih mencetak peringatan DEP0040 (`punycode`) dan DEP0169 (`url.parse()`), jadi CI belum bebas peringatan. Setelah analisis read-only V29-V32 dan review visual, pemilik memilih Opsi B untuk V29; perbaikannya di-merge ke `main` lewat PR #19 (merge commit `63eab4c`, 30 Oktober 2026 07.01 WIB) dan berlaku di `character-lab`, sedangkan Project B menunggu V26. Pemilik lalu menyetujui 74 frame V29 dan memerintahkan baseline resmi `character-lab` versi `tahap-5-v29`; versi itu direkam di branch `baseline-character-lab-tahap-5-v29` dan di-merge ke `main` lewat PR #21 (`a03f98d`, 30 Oktober 2026 13.15 WIB), sehingga `tahap-5` menjadi versi historis dan tidak ada perubahan aktif di `pending-changes.json` sampai PR #23 menambah entri V30. Audit pasca-merge PR #21 (clean clone) tidak menemukan FAIL; temuannya hanya status merge yang belum diperbarui di dokumentasi (lihat V29). Setelah eksperimen read-only V30 dan Spike G di salinan sekali pakai, pemilik memilih V30 Opsi B (geometri B2) dan memberi ACC terbatas untuk implementasi, commit, push, dan satu PR tanpa merge dan tanpa baseline baru; perbaikannya di-merge ke `main` lewat PR #23 (merge commit `4cee5fb`, 30 Oktober 2026 16.23 WIB). Audit pasca-merge PR #23 (clean clone) tidak menemukan FAIL di kode, render, baseline, atau CI. Pemilik lalu menyetujui 251 frame V30 dan memilih baseline `tahap-5-v30`, yang direkam di branch `baseline-character-lab-tahap-5-v30` dan di-merge ke `main` lewat PR #24 (merge commit `e64a473`, 30 Oktober 2026 17.35 WIB). Sejak itu `tahap-5-v30` menjadi baseline resmi `character-lab`, V30 tercatat di `resolved`, dan tidak ada perubahan aktif di `pending-changes.json`. Audit pasca-merge PR #24 (clean clone) tidak menemukan FAIL di kode, render, baseline, atau CI, dan regresi `character-lab` vs `tahap-5` (T1) lulus 12/12 (lihat V30). Tahap 6 dimulai lewat 6A-1 (waktu relatif adegan): implementasinya di-merge ke `main` lewat PR #26 (`1c34331`, 31 Oktober 2026) dan mencatat T22 dan T23, tetapi sintaks barunya belum boleh dipakai untuk produksi atau perekaman baseline. Pemilik lalu memecah 6A-2 menjadi 6A-2a (sidik kompilasi, T22), 6A-2b (fixture browser multi-stage), dan 6A-2c (`castOverrides` dan kontinuitas). 6A-2a dikerjakan di branch lokal `tahap-6-a-compiled-hash` (belum di-commit) dan mencatat T24. Izin produksi sintaks baru menunggu 6A-2b dan persetujuan pemilik. V31 dan V32 tetap KNOWN ISSUE. Butir di bawah adalah kandidat, bukan rencana yang sudah disetujui; pemilik yang memilih isi tahap berikutnya.
